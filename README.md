# 女性角色创作工作包

这是一个以 Markdown 档案和 PowerShell 工具为核心的女性角色创作工作包。它把人物事实、连贯肖像、行为画像和服装搭配分开保存，并用约束抽样、量体计算和结构检查减少前后矛盾。

项目面向中文创作与成年角色设计。仓库只保存生成方法：规则、空白模板、工具、测试和使用说明。人物、搭配、关系网、草稿及待扩展事项均保存在本机 `输出/` 下，该目录由 Git 忽略。

## 快速开始

需要 PowerShell 7 或 Windows PowerShell 5.1。中文路径和脚本按 UTF-8 读取。下面的 `pwsh` 可替换为 Windows PowerShell 5.1 的 `powershell.exe`。

```powershell
# 在仓库根目录运行完整回归测试
pwsh -NoProfile -File .\女性角色创作\工具\回归测试.ps1

# 生成 3 个受约束的候选
pwsh -NoProfile -File .\女性角色创作\工具\抽样.ps1 `
  -Mode sample -Count 3 -AgeMin 24 -AgeMax 29 `
  -HeightBand 标准 -BodyType 匀称 -Background 中国背景

# 计算量体参考值
pwsh -NoProfile -File .\女性角色创作\工具\抽样.ps1 `
  -Mode measure -Height 166 -BodyType 匀称 -BustLevel 偏大 -HipLevel 明显
```

完整的创作流程在 [`女性角色创作/README.md`](女性角色创作/README.md)。规则先锁定人物事实，再确认行为画像、场景和逐套造型，最后写入两份同编号档案。

## 生成与校验

人物档案只保存稳定事实、人物速写和行为画像；临时发型、内衣、服装、鞋袜和配饰只写入搭配档案。搭配默认覆盖日常、居家、约会、运动/出行和正式活动，也可以按需扩展雨天、季节户外、短途旅行、社交和文化活动。

单份档案可以用检查工具核对：

```powershell
pwsh -NoProfile -File .\女性角色创作\工具\检查输出.ps1 `
  -PersonPath '.\输出\人物\编号-姓名.md' `
  -WardrobePath '.\输出\搭配\编号-姓名.md' `
  -RequireDetailedProfile
```

将示意路径替换为本机实际文件。场景不是默认五类时，另传 `-ExpectedScenes '场景一|场景二'`，顺序与确认清单一致。检查结果中的 `错误` 会阻止通过，`提示` 用于核对超出抽样参考范围的作者设定。

多人简表使用 `检查关系网.ps1 -PersonPath '.\输出\关系网\名称\人物.md' -WardrobePath '.\输出\关系网\名称\搭配.md'` 检查；扩写完整档案时按单人流程处理。

运行 `pwsh -NoProfile -File .\女性角色创作\工具\检查本地输出.ps1` 可自动检查本机所有单人档案的配对、编号唯一性和关系网，不需要在测试脚本登记人物。该扫描核对已有内容内部一致性；单次交付仍须核对作者确认的场景清单。

修改规则、模板或工具后运行回归测试。测试只在临时目录构造最小数据，覆盖抽样、量体、有效年龄、人物与搭配结构、关系网简表及仓库边界，不依赖本机生成内容。新克隆的仓库无需任何人物档案即可运行测试。

提交前运行 `pwsh -NoProfile -File .\女性角色创作\工具\检查仓库边界.ps1`。即使通过 `git add -f` 强制加入输出，边界检查也会拒绝。生成内容的备份单独进行。
