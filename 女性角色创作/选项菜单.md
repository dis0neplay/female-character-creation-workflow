# 交互

先按 `人物规则.md` 核对已定事实、现有人物关系和抽样约束，再抽未指定项。只对冲突或会改变结果的关键歧义发一个短问句。作者希望挑选时调用 `工具/抽样.ps1 -Mode sample -Count 3` 并传入适用约束，展示三条姓名候选、年龄、背景、身高体型和几个外观锚点；否则抽一条。挑选提示为“回复编号、重抽、随机选一个，或直接写你的设定”。

默认逐项确认。每次只显示当前待判断的草案和一个确认问题；作者修改或重抽时只改当前未锁定部分。作者明确说“直接生成”“全部按你定”或“不需逐项确认”时使用快速模式：内部完成同样的事实核对、造型规划和校验，直接交付；仍须追问真正的冲突或关键歧义。

1. **面貌**：先用一行写姓名、年龄、文化背景及已确认关系，再用一段连贯文字呈现面貌，随后列出 `人物模板.md` 面貌部分的全部具体事实。结尾只问“姓名、年龄、背景和面貌确认吗？可回复确认、修改或重抽。”收到确认后锁定。
2. **身材**：展示身材部分的全部字段与量体。文字先说整体轮廓，再给短句和数值；不复述已锁定的面貌。结尾只问“身材确认吗？可回复确认、修改或重抽。”修改哪项就只重算受影响的数值。
3. **行为画像**：依据作者已定的性格与外在表现，提出一段包含两种稳定反应和一个有条件反差的草案；有已确认关系的人物，再用同一普通情境对照各自的行动与表达，不暗设经历或关系事件。只问“行为画像确认吗？可回复确认，或指出要调整的反应与关系表现。”收到确认后锁定。
4. **场景**：列出场景名、套数、风格、露肤强度及影响穿搭的天气、地点和着装要求；未知写“未设定”。默认建议上班／学习、居家休闲、出门约会、运动／出行、正式活动，每场景两套；人物身份未知时，把上班／学习改成不预设身份的活动。需要丰富衣橱时，从雨天日常、季节户外／短途旅行、社交／文化活动、婚礼／宴会、面试／会议、夜间外出中按需选择，至少覆盖天气、长距离行动、社交礼仪三类条件变化。作者已指定的场景优先。无环境限制时，居家与约会可列“高”，日常外出与无着装限制的正式活动列“偏高”；工作、运动或寒冷户外按功能收敛。把作者指定的风格和黑丝、蕾丝等视觉偏好分配到各场景，避免每套重复同一信号。结尾只问“这些搭配场景、风格和露肤强度确认吗？可回复确认，或调整场景、套数与条件。”
5. **造型方向**：场景确认后，每套一行：`1. 主色＋廓形；露肤部位；上身内衣方式；鞋型`，必要时加转场处理。上身内衣写支撑形式与领口、肩背相容的细节；每项给一个确定方案。场景标题、逐套方向及结尾确认句构成全部输出，结尾只问“这些造型方向确认吗？可回复全部确认，或指出要调整的方案。”作者已明确给定每套方向时，此步视为确认。

全部锁定后，先把面貌与身材写成 `人物速写`，再把已确认的反应写成 `行为画像`，随后按 `搭配规则.md` 扩写完整搭配。完成文字编辑和穿用核对后写入；作者要求“先预览”时，先展示两个文件的完整预览并等待确认。后续只改人物时检查受影响的搭配；只改搭配时不重选人物。
