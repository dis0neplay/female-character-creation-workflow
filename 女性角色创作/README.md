# 女性人物与场景搭配

这是仓库中可独立使用的创作工作包。仓库根目录的 README 提供项目说明、许可和贡献规则；本文件说明人物生成的具体操作。

在 Codex 中打开 `dsh` 根目录，输入“生成一名成年女性人物”，可直接补充年龄、关系、外貌、风格、场景和禁忌。提到现有人物时，系统先核对其档案；未指定的特征才在已知约束内抽样。

默认依次确认面貌、身材、行为画像、场景清单和每套造型方向。每次可回复“确认”“修改”或“重抽”，已确认部分保持不变。说“让我挑”会先看到三个简短方向；明确说“直接生成”或“全部按你定”可走快速模式。说“先预览”则在写文件前展示完整内容。

定稿生成同编号的两份文件：

- `输出/人物/编号-姓名.md`：稳定事实、连贯的人物速写，以及供核对的面貌和身形资料；没有穿搭。
- `输出/搭配/编号-姓名.md`：只覆盖已确认的场景，每场景至少两套；先写可见效果，再列内衣、发型、衣服、鞋袜和配饰。

这些文件只保存在本机，不提交 Git。多人关系网与简要造型放在 `输出/关系网/<名称>/人物.md`、`搭配.md`，按 `关系网模板.md` 和 `工具/检查关系网.ps1` 核对；扩写为完整单人档案时再分配稳定编号并补齐确认流程。

写入前检查人物是否有独立辨识度、关系和经历是否有依据、造型能否按场合实际穿用。写入后用 `工具/检查输出.ps1` 核对结构、量体和场景。后续可说“为 001 追加雨天通勤”“把约会搭配换成更简洁的”“只在对话里看看”。改搭配不重选人物；身形或发长变化时会核对受影响的搭配。

工作包规则在 `人物规则.md`、`选项菜单.md` 和 `搭配规则.md`；`工具/抽样.ps1` 提供受约束的候选与量体计算。搭配默认覆盖五个核心场景，需要更完整衣橱时可按人物需求增加雨天日常、季节户外／短途旅行和社交／文化活动。根目录 `输出/待扩展/` 只记录明确标注的未定事项。修改方法后运行 `工具/回归测试.ps1`；它在临时目录验证工具行为，不读取本机档案。提交前运行 `工具/检查仓库边界.ps1`。共享资料库及小说进度文档有其他用途，本工作包不加载它们。
