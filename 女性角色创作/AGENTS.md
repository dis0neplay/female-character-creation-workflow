# 女性人物与场景搭配 Agent

工作区根目录是本文件的父目录。人物与搭配分别存入根目录的 `输出/人物/`、`输出/搭配/`，文件同名为 `编号-姓名.md`。创作对象年满 18 岁；人物文件存稳定事实与连贯肖像，搭配文件存衣物、临时发型与场景方案。

## 按任务读取

- 新建人物：读 `人物规则.md`、`选项菜单.md`、`人物模板.md`；场景确认后读 `搭配规则.md`、`搭配模板.md`。涉及现有人物关系时，抽样前读被提及的人物档案。
- 修改人物：读 `人物规则.md` 和人物文件；身形或发长改变时，再读搭配文件与 `搭配规则.md` 并修正受影响方案。
- 新增或修改搭配：读人物文件、`搭配规则.md` 和搭配文件；新增场景先确认清单，不重跑人物生成。
- 整理旧输出或修改本工作包：读受影响的规则、模板、工具与输出，保留作者已确认事实。

路径以本文件所在目录为基准；`输出/` 以父目录为基准。PowerShell 直接运行 `.ps1` 工具；中文 Markdown 优先用文件编辑工具写，经 PowerShell 写入时显式用 UTF-8。`资料库/` 与 `资料库进度/` 服务其他写作任务。

## 新建流程

1. 核对作者已定条件与现有人物参照，确认姓名及亲属关系；按 `人物规则.md` 给抽样器传入年龄、背景和身形等约束，只填空白。关键歧义只问一个短问题。
2. 按 `选项菜单.md` 依次确认面貌、身材、行为画像、场景清单和逐套造型方向；作者明确要求快速生成时走该文件的快速模式。确认阶段不向 `输出/` 写文件，重抽只改未锁定项。
3. 事实锁定后写 `人物速写`，把面貌、体态与神情连成一幅可辨认的画面；另写连贯的 `行为画像`，呈现稳定反应及有条件的反差。量体留在资料栏。搭配先写可见效果，再填内衣、发型、衣服、鞋袜与配饰。逐套核对支撑、防透、露肤、发长、活动与天气。
4. 成文后再作一次编辑检查：每个人物有自己的两三个识别点和可辨认的行事方式，修辞不遮盖事实，场景未暗中补造职业、学籍、子女或经历。作者要求“先预览”时展示两份完整文件并等待确认；其他情况直接写入。
5. 写入后运行 `工具/检查输出.ps1 -PersonPath <人物文件> -WardrobePath <搭配文件> -RequireDetailedProfile -ExpectedScenes '<场景1>|<场景2>'`，列出全部确认场景；有错误就修正重查。新人物用未占用的稳定编号，重名追加序号，不覆盖其他人物。最终给两个路径和仍待定的项。

修改规则、模板、工具或批量整理既有输出后，运行 `工具/回归测试.ps1`。

只在对话预览时不写文件。增补场景或换装时只改对应搭配文件；已确认的旧方案可保留为备选，除非作者要求替换。输出文件只留人物事实和可穿的搭配，不写候选过程、规则解释或校验日志。
